# GitHub release checklist

- [x] Canonical G0 model/training source included.
- [x] Formal G0_BALANCED e53 checkpoint included and hashed.
- [x] Training contracts, selection evidence, and validation records included.
- [x] Aggregate Test/Validation/Generalization result artifacts included.
- [x] Raw simulation arrays and raw prediction arrays excluded.
- [x] `requirements.txt`, `LICENSE`, and `CITATION.cff` included.
- [ ] Replace the repository URL in `CITATION.cff`.
- [ ] Run a clean-machine smoke test after configuring local data paths.
- [ ] Configure Git LFS or GitHub Release assets for checkpoints.
- [ ] Confirm redistribution permissions for any separately obtained data.
- [ ] Add the final paper DOI when available.
